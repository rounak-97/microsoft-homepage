# Microsoft Homepage Clone

A responsive Microsoft-inspired landing page built with **HTML, CSS, and JS**. This project recreates a Microsoft-style homepage
layout

> **Live demo:** 

⟶ ""

## Features

-   Microsoft-inspired navigation and homepage layout
-   Responsive sections for desktop and smaller screens
-   Interactive image carousel with navigation controls
-   Mobile navigation menu

## Built With

-   **HTML5** --- page structure
-   **CSS3** --- layout, styling, hover effects, and responsive design
-   **Vanilla JavaScript** --- interactive controls and page behavior

No build tool, package installation, or backend server is required for
the static website.

## Project Structure

``` text
microsoft-homepage-clone/
├── index.html    # Main webpage
├── style.css     # Styling and responsive rules
├── script.js     # Interactive behavior
└── README.md     # Project documentation
```

## Run Locally

### Option 1: Open the file directly

1.  Download or clone this repository.
2.  Open the project folder.
3.  Double-click `index.html` to open it in your browser.

### Option 2: Use Visual Studio Code

1.  Open the project folder in Visual Studio Code.
2.  Open `index.html`.
3.  Use a local preview extension such as **Live Server**, if installed,
    to launch the page in a browser.
